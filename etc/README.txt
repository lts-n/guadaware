/etc/guadaware-build is a document used by Guadaware to identify its version, image build number and other things specified by the device's manufacturer.

Its content depending on the Guadaware build should be:
guadaware-(Version. Examples: 26-stable, 26-beta)-(Build number)-(Architecture. Examples: arm, arm64, x86, x86_64)-(OS in which it's based. Examples: pmos, android, mobian, debian, ubuntutouch)-(Device manufacturer. Examples: Samsung, Guadafón, BQ)-(Device codename/model)

For example, on the Guadafón Telefunny it should say: 
guadaware-26-stable-(build)-arm64-android-guadafon-telefunny
